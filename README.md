# 🏸 羽毛球六点步伐训练

把手机放在球场中央，跟着**全屏箭头**做六点步伐（左上 / 右上 / 左 / 右 / 左下 / 右下）。

纯前端单页应用，无需安装、无依赖，打开 `index.html` 即可使用。

## 功能
- **两个界面**：设置界面 + 训练界面（训练界面只有铺满全屏的箭头，远处也看得清）
- **固定间隔**：自定义每 N 秒换一个方向（0.5–60 秒，支持小数）
- **随机间隔**：设定最短/最长秒数，每次换向的间隔都随机，节奏不可预测
- **允许重复方向**（可关）；重复时箭头会闪一下 + 提示音，确保你知道"又来了"
- **六个方向可单独开关**，比如只练后场两点
- 颜色区分区域：青色=前场、黄色=两侧、粉色=后场
- 训练时长：不限 / 按次数 / 按时间；开始前倒计时
- 提示音、中文语音播报、震动（安卓）、左右镜像
- 横屏时斜向箭头固定 45°，竖屏时斜向箭头对准屏幕角
- 屏幕常亮（Wake Lock）、自动全屏、支持离线（PWA，可"添加到主屏幕"）
- 训练结束显示每个方向出现次数
- 设置自动保存在本机

## 操作
- 点屏幕任意位置：暂停 / 继续
- 左上角 ✕ 或手机返回键：结束训练

## 部署到手机
最简单：在仓库 Settings → Pages 里开启 GitHub Pages（分支选这个分支，根目录），
用手机浏览器打开生成的网址，再"添加到主屏幕"，之后球馆没网也能用。

> 屏幕常亮、离线缓存需要 HTTPS（GitHub Pages 满足）；直接打开本地文件也能训练，只是这两项可能不生效。

# 🏸 羽毛球六点步伐训练

把手机放在球场中央，跟着**全屏箭头**做六点步伐（左上 / 右上 / 左 / 右 / 左下 / 右下）。

纯前端单页应用，无需安装、无依赖，打开 `index.html` 即可使用。

## 功能
- **两个界面**：设置界面 + 训练界面（训练界面只有铺满全屏的箭头，远处也看得清）
- **固定间隔**：自定义每 N 秒换一个方向（0.5–60 秒，支持小数）
- **随机间隔**：设定最短/最长秒数，每次换向的间隔都随机，节奏不可预测
- **允许重复方向**（可关）；重复时箭头会闪一下 + 提示音，确保你知道"又来了"
- **六个方向可单独开关**，比如只练后场两点
- **实战概率**（默认开）：长期占比约 后场 42% / 前场 38% / 两侧 20%（估算值，见代码注释）；关掉则等概率
- **左右（接杀）永不连续**：上一拍是左/右，下一拍一定是斜向
- 颜色区分区域：青色=前场、黄色=两侧、紫色=后场
- **神经抑制（反向指令）**：按设定概率箭头变成红色，要往反方向跑（左上↔右下、右上↔左下、左↔右）
- **假动作**：按设定概率先闪一个斜向箭头（停留时间可调，如 0.3 秒），再突然换成另一个斜向；只在四个斜向之间发生，左右（接杀步伐）不做假动作
- 训练时长：不限 / 按次数 / 按时间；开始前倒计时
- 提示音、中文语音播报、震动（安卓）、左右镜像
- 斜向箭头横竖屏都固定 45°
- **防守练习模式**：挑球 → 全屏倒计时圆环（一位小数）→ 对方 杀 / 吊 / 平高（概率可调）。接杀 → 对方放网（大概率同侧、小概率对角）→ 挑球；接吊直接挑球；接平高抽后场 → 缩短的圆环 → 接杀 → 放网 → 挑球。圆环时长随机可调，反向与假动作可开关
- **启动练习模式**：默认每 1 秒换一个方向，黄色箭头=往箭头方向，红色箭头=往反方向，背景始终黑色，不做假动作
- 屏幕常亮（Wake Lock）、自动全屏、支持离线（PWA，可"添加到主屏幕"）
- 训练结束显示每个方向出现次数
- 设置自动保存在本机

## 操作
- 点屏幕任意位置：暂停 / 继续
- 左上角 ✕ 或手机返回键：结束训练

## 部署到手机
最简单：在仓库 Settings → Pages 里开启 GitHub Pages（分支选这个分支，根目录），
用手机浏览器打开生成的网址，再"添加到主屏幕"，之后球馆没网也能用。

> 屏幕常亮、离线缓存需要 HTTPS（GitHub Pages 满足）；直接打开本地文件也能训练，只是这两项可能不生效。
